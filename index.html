FaVOR

Factor Validation through Observable Reasoning

Findings of EMNLP 2026 · 채택

문제. 백테스트 성과가 높더라도 생성된 금융 팩터가 최초의 경제 가설을 표현한다고 보장할 수 없습니다.

방법. 가설을 관측 조건으로 분해하고 후보 수식의 통계·의미적 일관성을 검증합니다. 검증 실패의 근거를 다음 후보 수정에 반영한 뒤, 검증된 팩터를 조합하고 평가합니다.

공동 제1저자. 4개 Agent의 실행 흐름·입출력·프롬프트·구조화 출력과 검증 로직을 공동 설계했습니다.

결과. 2025년 논문 보고 기준 테스트 정보비율(IR)은 CSI 500 1.5295, S&P 500 1.1315였습니다. CSI 500의 검증 제거 실험에서는 0.1526으로 낮아졌습니다. 연구 백테스트 결과입니다.

RESEARCH CASE / FAVOR

수익률을 넘어, 생성 수식이 가설을 측정하는지 검증

가설·수식·관측 통계의 연결과 검증 단계의 효과를 함께 확인했습니다.

수익이 난다는 사실만으로, 수식이 경제 가설을 구현했다고 말할 수 있을까?

금융 팩터는 가격·거래량 등으로 계산한 값으로, 투자 아이디어를 데이터에서 측정하는 역할을 합니다. 예를 들어 ‘급락한 뒤 장중에 회복한 종목’이라는 아이디어라면, 수식은 단순히 가격 변화가 큰 종목이 아니라 급락과 회복이라는 조건을 실제로 구분해야 합니다.

왜 발생하는가 · 자연어 가설을 수식으로 바로 옮기고, 수익률로만 선택하기 때문

자연어에는 ‘급락’, ‘회복’, ‘거래 활동’처럼 여러 조건이 함께 들어 있습니다. LLM이 이를 한 번에 수식으로 만들면 일부 조건이 빠지거나, 의도와 다른 지표가 들어가도 수식 자체는 정상적으로 계산될 수 있습니다. 이후 백테스트 수익률만 기준으로 후보를 선택하면, 특정 기간에서 우연히 잘 맞은 상관관계와 가설을 측정하는 신호를 구분하기 어렵습니다.

논문에서 다룬 관측 조건 예시 · 장중 회복

팩터값이 큰 종목일수록 종가가 당일 고가에 가까워지는지 살펴볼 수 있습니다. 기대와 반대 방향의 통계가 나타난다면, 그 수식은 수익률이 높더라도 ‘장중 회복’을 측정한다는 근거가 부족합니다. 여기서 확인하는 것은 관측 조건의 일치이며, 수익의 경제적 원인 전체가 증명되는 것은 아닙니다.

왜 문제인가 · 실패했을 때 무엇이 달라졌는지 설명하기 어렵다

가설과 수식의 연결이 불명확하면 시장 국면이 바뀌어 성능이 낮아졌을 때, 가설 자체가 맞지 않는지 수식이 가설을 잘못 표현했는지 구분하기 어렵습니다. 후보를 수정할 때도 ‘수익률을 높인다’는 목표 외에 무엇을 바꿔야 하는지 판단 근거가 약해집니다.

연구 질문 · 거래 평가에 앞서 가설을 관측 조건으로 나누고, 각 수식이 의도한 조건을 측정하는지 통계 증거로 확인할 수 있을까? 실패 근거를 다음 후보 수정에도 사용할 수 있을까?

구현의 핵심과 성능 개선
핵심 기능

가설을 관측 조건으로 분해하고 조건별 수식을 생성합니다. 구조화된 Agent 출력을 다음 단계의 입력으로 연결하고, 관측 통계·의미 검증의 실패 근거를 후보 수정에 반영한 뒤 통과 수식을 통합합니다.

기술적 차별점

수익률을 최적화하기 전에 수식과 관측 조건의 대응을 검사합니다. LLM의 의미 해석과 명시적 통계 판정을 분리해, 판정 근거를 추적하고 같은 실패를 다음 후보의 수정 입력으로 사용할 수 있게 합니다.

성능 개선·최적화

검증된 수식을 거래 평가에 연결하고 검증 기간에서 임계값을 선택합니다. 검증 제거 실험 대비 CSI 500 정보비율은 0.1526→1.5295였습니다. 이는 전체 검증 단계의 거래 성능 기여이며 처리 속도나 토큰 절감의 측정값은 아닙니다.

가설의 조건 누락과 수익률 중심 선택을 서로 다른 단계에서 다루기

FaVOR는 가설에서 수식으로 바로 넘어가는 대신, 관측 조건을 먼저 명시하고 수식이 그 조건을 측정하는지 확인한 뒤 거래 평가에 사용합니다. 경제 가설의 표현과 거래 성능을 나눠 점검하도록 구성했습니다.

01 · 여러 조건이 한 수식에서 누락되는 문제 → 관측 조건 분해

선택 이유. ‘급락 후 장중 회복’ 같은 가설은 여러 조건을 포함합니다. 이를 한 번에 수식으로 만들면 어떤 조건이 반영됐는지 추적하기 어렵기 때문에, 가격·거래량으로 확인할 수 있는 조건으로 나눕니다.

작동 방식. 분해된 조건마다 후보 수식을 생성하고, 해당 수식이 측정해야 할 지표와 기대 방향을 연결합니다. 이후 검증도 전체 가설에 대한 막연한 평가가 아니라 조건별로 수행할 수 있게 합니다.

02 · 수익률만으로 의미 일치를 판단하는 문제 → 관측 통계 검증

선택 이유. 계산 가능한 수식이라는 사실과 가설을 측정한다는 사실은 다릅니다. 따라서 후보의 수익률 외에, 수식값이 변할 때 가설에서 기대한 시장 조건도 함께 달라지는지 살핍니다.

작동 방식. 날짜별 팩터값으로 종목을 5분위로 나누고 조건별 지표의 분포 변화를 비교합니다. LLM은 조건·지표·기대 방향의 의미를 연결하며, 실제 통계 변화는 명시적 규칙으로 판정합니다. 예를 들어 장중 회복 조건에서는 높은 팩터값이 종가의 당일 고가 접근과 연결되는지 확인합니다.

03 · 실패 원인을 모른 채 수식을 바꾸는 문제 → 실패 근거 기반 수정·통합

선택 이유. 통과 여부만 전달하면 다음 후보에서 무엇을 바꿔야 할지 알기 어렵습니다. 기대 방향과 실제 통계가 어디서 어긋났는지를 수정의 입력으로 사용합니다.

작동 방식. 검증 실패 근거를 다음 후보에 반영하고, 통과한 수식을 통합해 원래 가설을 표현합니다. 이후 학습·검증·테스트를 분리한 거래 평가에 연결합니다.

효과를 확인한 방법

검증 단계를 제거한 실험과 비교해 거래 성능 기여를 살폈고, 블라인드 전문가 평가 100건으로 의미 일치성을 별도로 확인했습니다. 정량 결과와 부분 일치·불일치 사례는 ‘검증’과 ‘성과’ 탭에서 확인할 수 있습니다.

본인 기여 · 공동 제1저자
4개 Agent의 실행 흐름·입출력·프롬프트·구조화 출력과 검증 로직을 공동 설계했습니다.

수익률, 검증 단계의 효과, 의미 일치성을 각각 확인

학습·검증·테스트 기간을 분리하고 거래비용을 반영해 평가했습니다. 검증 단계 제거 실험으로 구성 요소의 효과를 확인하고, 블라인드 전문가 평가 100건으로 생성 결과의 의미 일치성을 별도로 살폈습니다.

예를 들어 장중 회복 조건에서는 팩터값이 커질수록 종가가 당일 고가에 가까워지는지 확인합니다. 반대 방향의 통계가 나타나면 실패로 판정하고 그 근거를 후보 수정에 반영합니다.

관측 조건과 통계의 일치는 확인할 수 있지만, 그것만으로 경제적 인과 설명이 완결되는 것은 아닙니다. 전문가 평가의 ‘일치’와 ‘부분 일치’를 구분해 보고했습니다.

ARTE

Agentic Refinement through Trade Execution

학위논문 · 연구 / 원고 작성 중

문제. 같은 OHLCV 집계에서도 체결 순서와 호가 상태는 다를 수 있습니다. 총손익만으로는 실패한 진입 조건과 실제 주문 체결 과정을 구분하기 어렵습니다.

방법. 틱 단위 관측을 실행 가능한 진입 표현식으로 구성합니다. 주문 대기·체결·청산 기록을 요약하고, Feedback·Refinement Agent가 실행 증거를 바탕으로 다음 후보를 개선하도록 설계합니다.

학위논문 연구 및 작성. 틱 단위 진입 표현식과 거래 실행 증거를 연결하는 Agent 개선 방법을 연구하고 있습니다.

RESEARCH CASE / ARTE

틱 단위 관측과 거래 실행 증거를 다음 전략으로 연결

진행 중인 학위논문 · 현재 설계와 추가 검증 계획을 구분합니다.

요약된 가격과 최종 손익만으로, 다음 진입 조건을 어떻게 고칠까?

OHLCV는 일정 시간의 시가·고가·저가·종가·거래량을 요약합니다. 구간 전체의 움직임을 보기에는 유용하지만, 그 안에서 어떤 거래가 먼저 일어났고 호가 잔량이 어떻게 바뀌었는지는 담지 않습니다. 짧은 시간의 진입 판단을 연구할 때는 바로 이 정보가 필요합니다.

왜 발생하는가 · 집계 과정에서 순서와 주문 대기 상태가 사라진다

서로 다른 가격 경로도 시작·끝 가격, 최고·최저 가격과 총거래량이 같으면 같은 OHLCV가 됩니다. 호가에 주문이 추가되거나 취소되는 변화도 이 요약만으로는 알 수 없습니다. 반대로 전체 틱 기록을 그대로 LLM에 전달하면 정보량이 커져, 어떤 가격 단계와 시간 관계를 진입 조건으로 사용할지 선택하기 어렵습니다.

이해를 위한 예시 · 같은 봉, 다른 경로

한 구간에서 ‘먼저 상승한 뒤 하락’한 경로와 ‘먼저 하락한 뒤 상승’한 경로는 같은 시가·고가·저가·종가를 가질 수 있습니다. 같은 거래량도 가능합니다. 하지만 어느 시점에 주문을 냈는지, 그때 앞서 대기하던 주문과 잔량이 어땠는지에 따라 체결 과정은 달라질 수 있습니다.

왜 문제인가 · 신호의 적절성과 주문 체결의 실패가 섞인다

진입 신호 뒤 가격이 유리하게 움직여도 주문이 체결되지 않을 수 있습니다. 체결 시점이 달라지거나 거래비용이 반영되면 결과도 달라집니다. 최종 손익만 전달하면 조건이 잘못됐는지, 체결 과정이 문제였는지, 체결 후 기대 경로가 어긋났는지를 구분하기 어렵고, Agent의 수정도 원인과 무관한 변경이 될 수 있습니다.

연구 질문 · 필요한 호가·시간 관계를 실행 가능한 진입식으로 표현하고, 진입 → 주문 → 체결 → 청산의 증거를 요약해 다음 표현식의 수정 근거로 연결할 수 있을까? 학위논문 연구 진행 중.

구현의 핵심과 성능 개선
핵심 기능

호가 단계·시간 관계를 진입 표현식으로 만들고 후보 파라미터와 함께 실행합니다. 진입·주문·체결·청산을 연결한 거래 요약을 Feedback·Refinement Agent에 전달해 다음 후보를 생성합니다.

기술적 차별점

원시 틱 기록 전체를 프롬프트로 전달하는 대신 실행 가능한 관계를 제안하도록 합니다. Agent가 보는 요약과 전체 기록에서의 실행 평가를 나누고, 최종 손익 외에 체결 과정과 진입 관측을 수정 근거로 연결합니다.

성능 개선·최적화

표현식은 전체 Discovery 기록에서 평가하고 비교 가능한 거래 요약을 Agent에 전달해 입력 범위를 구성합니다. Validation에서 후보를 선택한 뒤 Test 전략을 고정합니다. 입력 구조의 설계이며 지연시간·메모리·토큰 절감률은 별도로 측정한 결과가 없습니다.

집계에서 사라진 관계를 표현하고, 손익 뒤의 실행 과정을 피드백으로 연결

ARTE는 전체 틱 기록을 LLM에 그대로 읽히는 대신, 필요한 호가·시간 관계를 진입 표현식으로 만들고 전체 기록에서 실행합니다. 실행 뒤에는 최종 손익만이 아니라 주문·체결·청산의 증거를 후보 수정에 전달합니다.

01 · OHLCV에 순서·호가 정보가 없는 문제 → 실행 가능한 시공간 표현식

선택 이유. 짧은 시간의 진입 판단에는 가격 단계별 잔량과 그 변화·지속·순서가 필요합니다. 원시 기록 전체를 프롬프트에 넣는 방식은 정보량이 커서, 필요한 관계를 선택해 계산하는 구조로 설계했습니다.

작동 방식. 사용 가능한 특징과 연산자를 명시하고, 호가 단계 간 관계와 시간 변화를 표현식으로 구성합니다. Agent가 제안한 진입식과 파라미터를 Discovery 기록에서 실행합니다. 각 진입 판단은 해당 시점까지의 관측만 사용합니다.

02 · 신호 실패와 체결 실패를 구분하기 어려운 문제 → 진입부터 청산까지 추적

선택 이유. 가격이 기대한 방향으로 움직여도 주문이 체결되지 않을 수 있습니다. 조건의 적절성과 실행 과정의 영향을 함께 보려면 진입 관측과 주문 결과가 연결돼 있어야 합니다.

작동 방식. 주문 대기·부분 체결·거래비용을 반영하고, 진입 → 체결 → 체결 후 관측 → 청산 결과를 연결합니다. 수익·손실 거래별로 진입 특징과 기대·실제 경로를 비교 가능한 거래 요약으로 정리합니다.

03 · 최종 손익만으로 다음 수정이 모호한 문제 → 근거를 사용하는 Agent 개선 루프

선택 이유. ‘손실이 났다’는 요약보다 어느 관측과 실행 과정이 결과에 연결됐는지를 제공해야 진입 조건의 수정 근거가 구체화됩니다.

작동 방식. Feedback Agent가 거래 요약을 해석하고 관측·진단·수정 예측을 구분합니다. Refinement Agent는 거래 요약과 피드백을 함께 사용해 다음 진입식을 제안하고, 다시 백테스트합니다.

검증을 위한 설계와 현재 상태

Discovery에서 생성·개선하고 Validation에서 후보를 선택한 뒤, 전략을 고정해 Test에서 평가합니다. 학위논문 연구·원고 작성 중이며 추가 미사용 기간 검증은 계획 단계입니다. 실행 기록은 수정 근거로 사용하며 실제 원인의 인과 증명과는 구분합니다.

본인 기여 · 학위논문 연구 및 작성
틱 단위 진입 표현식과 거래 실행 증거를 연결하는 Agent 개선 방법을 연구하고 있습니다.

전략을 만드는 기간과 평가하는 기간을 분리

Discovery에서 후보를 생성·개선하고, Validation에서 후보를 선택합니다. 선택한 전략을 고정한 뒤 Test에서 평가하는 구조입니다.

진입 판단에는 해당 시점까지의 관측만 사용하도록 제한합니다. 실행 기록을 관측·진단·수정 예측으로 구분해, 다음 후보에서 어떤 변화가 기대되는지 추적하도록 설계했습니다.

학위논문 연구·원고 작성 중입니다. 추가 미사용 기간의 검증은 계획 단계이며, 완료된 검증으로 표기하지 않습니다.

현재 산출물: 진입 표현식과 실행 증거를 잇는 개선 구조

집계 수익만 전달하던 피드백을 주문·체결·청산과 진입 관측에 연결하는 연구 구조를 정리했습니다. 틱 단위 표현식과 거래 요약, Agent의 개선 루프를 학위논문에 구성하고 있습니다.

이 연구의 결론은 현재 ‘실행 과정에서 얻은 증거를 후보 개선에 활용하는 설계’입니다. 현재 산출물은 표현식·거래 요약·평가 절차이며, 추가 미사용 기간 검증을 이어갈 계획입니다.

Applied Sciences · 2026

문제. 신체 움직임만으로 스윙을 표현하면 클럽과 신체의 상호작용을 충분히 반영하기 어렵습니다.

방법. 신체 13개·클럽 2개 키포인트를 시공간 그래프로 통합하고 ST-GCN·STGAT을 적용했습니다. Integrated Gradients와 궤적 교체 분석으로 예측 근거를 살폈습니다.

신체·클럽의 통합 표현을 예측과 동작 해석에 활용

공동 연구의 정량 결과와 본인의 소프트웨어 구현 범위를 구분했습니다.

몸의 자세를 잘 읽는 모델이, 공의 비행 결과도 충분히 설명할 수 있을까?

골프 스윙 분석에는 두 가지 질문이 있습니다. 하나는 이 움직임이 어떤 타구 결과와 연결되는가이고, 다른 하나는 어느 구간의 어떤 움직임을 점검할 것인가입니다. 자세 분류나 전문가 스윙과의 유사도만으로는 두 질문에 모두 답하기 어렵습니다.

왜 발생하는가 · 신체 표현에 도구의 움직임이 빠져 있고, 결과와의 연결도 부족하다

신체 관절만 입력하면 모델은 팔·다리·몸통의 움직임을 볼 수 있지만 클럽의 움직임을 직접 관측하지 못합니다. 비슷한 신체 자세라도 클럽 궤적과 임팩트 조건은 달라질 수 있어, 신체·클럽의 협응을 충분히 표현하기 어렵습니다. 또한 자세의 모양을 비교하는 것과 실제 공 속도·발사 방향·회전축을 예측하는 것은 다른 평가 문제입니다.

이해를 위한 예시 · 비슷한 자세, 다른 타구

두 스윙의 신체 자세가 비슷해 보여도 클럽 헤드의 경로와 시점은 다를 수 있습니다. 신체만 보는 모델에는 이 차이가 직접 입력되지 않습니다. 예측값만 알려주는 경우에는 결과가 좋지 않은 이유를 어느 스윙 구간과 연결해 점검할지도 알기 어렵습니다.

왜 문제인가 · 정확한 예측과 활용 가능한 설명 사이에 간격이 생긴다

‘공이 오른쪽으로 갈 가능성이 높다’는 예측을 받더라도, 모델이 어떤 관절·클럽 움직임과 시점에 주목했는지 모르면 구체적인 점검으로 연결하기 어렵습니다. 따라서 신체와 클럽을 함께 표현하고, 실제 타구 측정값에 연결하며, 구간별 예측 기여도를 해석하는 과정이 필요했습니다.

연구 질문 · 통합 시공간 그래프가 신체 단독 표현보다 타구 결과 예측에 도움이 되는가? 기여도와 궤적 교체 분석으로 점검할 동작·시점의 예시를 제시할 수 있는가? 예측 근거 분석과 실제 코칭 효과의 검증은 구분합니다.

구현의 핵심과 성능 개선
핵심 기능

영상의 신체·클럽 키포인트를 통합 그래프로 구성하고 회전축·발사 방향·공 속도를 예측합니다. 구간별 기여도와 궤적 교체의 예측 변화를 연결해 점검할 움직임을 시각화합니다.

기술적 차별점

신체만 분석하는 표현에 클럽의 움직임을 함께 넣고, 자세의 모양 대신 TrackMan 타구 측정값과 연결해 평가합니다. 분류·회귀 성능과 구간별 예측 근거를 함께 보고 목표별 차이를 살핍니다.

성능 개선·최적화

클럽 통합 STGAT의 회전축 정확도는 75.00%→78.33%로 3.33%p 향상됐습니다. 속도 예측에서는 RF의 RMSE가 더 낮아 목표별 모델 차이를 확인했습니다. 모든 목표에 동일한 모델 우위를 주장하지 않습니다.

표현에 빠진 클럽을 넣고, 타구 측정값과 예측 근거를 함께 연결

골프 스윙 연구는 입력 표현의 한계, 실제 결과와의 연결, 점검 가능한 설명을 각각 다뤘습니다. 신체·클럽 통합 그래프와 타구 예측, 구간별 기여도 분석을 하나의 흐름으로 구성했습니다.

01 · 신체 입력에서 클럽 움직임이 빠지는 문제 → 15개 키포인트 통합 그래프

선택 이유. 신체 자세가 비슷하더라도 클럽 경로가 다르면 타구 결과가 달라질 수 있습니다. 클럽 움직임을 입력에서 직접 표현하고 신체와의 관계도 모델링하도록 했습니다.

작동 방식. 신체 13개·클럽 2개 키포인트를 하나의 시공간 그래프로 구성합니다. 그래프는 키포인트 사이의 연결과 시간 변화를 담고, ST-GCN·STGAT으로 이 관계를 학습합니다.

02 · 자세의 유사도가 타구 결과를 설명하지 못하는 문제 → 실제 측정값 기반 예측

선택 이유. 자세가 전문가와 비슷한지 평가하는 것만으로는 공 속도나 방향과의 정량적 연결을 확인하기 어렵습니다. 움직임과 같은 스윙의 타구 측정값을 대응시켰습니다.

작동 방식. 골퍼 6명의 정제 스윙 321개를 TrackMan 측정값과 연결해, 회전축·발사 방향을 분류하고 공 속도를 회귀 예측합니다. 분류와 회귀의 평가 지표를 나눠 목표별 성능을 확인합니다.

03 · 예측값만으로 점검할 동작을 알기 어려운 문제 → 기여도·궤적 교체 분석

선택 이유. 결과 예측을 움직임 점검으로 연결하려면, 모델이 어느 구간의 어떤 관절·클럽에 주목했는지 살펴야 합니다. 기여도 분석과 입력 변화에 따른 예측 변화를 함께 확인했습니다.

작동 방식. Integrated Gradients로 구간별 키포인트 기여도를 산출하고 대표 정답·오답을 비교합니다. 개별 궤적을 교체했을 때 예측이 어떻게 바뀌는지 살펴, 8개 스윙 구간의 점검 방향을 피드백 예시로 시각화합니다.

효과를 확인한 방법

신체 단독과 신체·클럽 통합 STGAT을 비교해 회전축 정확도 3.33%p 향상을 확인했습니다. 속도 예측에서는 RF의 오차가 더 작아 목표별 차이도 보고했습니다. 기여도·궤적 교체는 예측 근거와 예측 변화의 분석이며 실제 코칭 효과는 후속 검증 대상입니다.

대표 정답·오답의 기여도 분포로 모델이 주목한 관절과 시점을 분석했습니다. 궤적 교체의 예측 변화를 함께 살펴 8개 스윙 구간의 점검 방향을 피드백 예시로 시각화했습니다.

RESEARCH CASE / SATELLITE

데이터 품질·복원 성능·현장 편차를 함께 검증

개인 담당 범위와 팀의 정량 결과를 나눠 설명합니다.

2km 격자의 온도 자료로, 도시 안의 세부 공간 변화를 볼 수 있을까?

기상위성 지표면온도 자료의 공간 격자가 2km이면, 그보다 작은 규모의 온도 차이를 직접 구분하기 어렵습니다. 도시·수계·농경지 등 서로 다른 공간 경계가 한 격자 안에 들어갈 수 있어, 지역 내부의 세부 변화를 살피려는 목적과 관측 해상도 사이에 간격이 생깁니다.

왜 발생하는가 · 부족한 공간 정보와 서로 다른 관측 조건이 함께 작용한다

저해상도 자료를 단순 확대하거나 보간해도 입력에서 관측하지 못한 세부 온도 정보를 그대로 얻을 수는 없습니다. 다른 위성의 고해상도 공간 정보를 활용하려 해도 위성마다 해상도·관측 시점이 다르고, 구름과 결측에 따라 이용 가능한 자료의 품질이 달라집니다. 위치·시점이 맞지 않은 입력과 기준 자료를 연결하면 학습·평가의 대응 관계도 어긋날 수 있습니다.

이해를 위한 예시 · 선명한 경계가 정확한 온도를 뜻하지는 않는다

복원 영상에서 강이나 능선의 경계가 뚜렷해져도, 해당 시점의 실제 온도가 정확하게 복원됐는지는 별도로 확인해야 합니다. 공간 정보를 주는 참조 영상의 시점이나 구름 조건이 다르면, 선명해 보이는 결과와 온도 오차가 서로 다르게 나타날 수 있습니다.

왜 문제인가 · 보기 좋은 복원과 현장에 맞는 복원을 구분해야 한다

하나의 평균 오차만 보면 도시·계절·시간대에 따라 커지는 편차를 놓칠 수 있습니다. Landsat과 비교하는 공간 복원 평가와 ASOS 지상관측의 편차 분석도 서로 다른 정보를 줍니다. 따라서 자료 품질·정합을 확인하고, 동일 조건의 모델 비교와 지역·시간별 오차 분석을 함께 수행해야 개선 여부와 남은 한계를 판단할 수 있습니다.

연구 질문 · 다중 위성자료의 품질과 대응 관계를 점검한 뒤 2km 자료를 250m로 복원하고, 공간 복원 오차와 현장 편차를 함께 검증할 수 있을까? 참여연구자로 데이터 구성·정합, 모델 비교·검증과 오차 분석에 참여했습니다.

구현의 핵심과 성능 개선
핵심 기능

다중 위성자료 정합·구름 및 결측 점검, GK2A 온도와 GK2B 공간 정보를 이용한 ×8 복원, Landsat 공간 검증·ASOS 편차 분석을 연결했습니다.

기술적 차별점

출력의 선명함만 보는 대신 참조 영상 품질과 온도 복원 오차를 함께 확인합니다. 보간·통계 기반 방법과 학습 기반 복원을 비교하고, 공간 검증과 지역·월·시간대의 현장 편차를 구분합니다.

성능 개선·최적화

공동 연구는 2020–2024년 자료를 train 881 / validation 110 / test 110 패치로 구성해 DCT-RRDBNet ×8을 재학습했습니다. Validation loss 기준 checkpoint를 선택했으며, 동일 조건의 이전 모델 대비 RMSE가 약 41.4% 감소했습니다. 재학습과 자료 구성 변화가 포함된 팀 결과입니다.

자료 대응 관계를 먼저 맞추고, 공간 복원과 온도 오차를 나눠 검증

위성 연구에서는 입력 자료의 품질·정합, 부족한 공간 정보의 복원, 지역·시간별 오차를 구분해 다뤘습니다. 모델을 바꾸는 것과 함께 어떤 자료를 연결하고 어떤 조건에서 비교하는지를 점검했습니다.

01 · 위성별 관측 조건이 다른 문제 → 해상도·시점 정합과 구름·결측 점검

선택 이유. 입력과 기준 자료의 위치·시점이 어긋나면 서로 다른 상태를 같은 학습 사례로 묶을 수 있습니다. 고해상도 참조 영상의 구름·품질 차이도 복원 결과에 영향을 줄 수 있어 모델 평가 전에 자료의 대응 관계를 확인했습니다.

작동 방식. GK2A·GK2B·Landsat 자료의 해상도와 시점을 정렬하고 구름·결측 등 품질 조건을 점검합니다. 학습·검증 데이터 구성과 참조 영상 품질에 따른 복원 결과 비교에 참여했습니다.

02 · 단순 확대만으로 세부 정보를 얻기 어려운 문제 → 고해상도 참조를 활용한 ×8 복원

선택 이유. 보간은 입력 격자를 늘릴 수 있지만 세부 온도 구조를 직접 관측한 것은 아닙니다. GK2A의 온도 분포에 GK2B의 공간 경계 정보를 연결해 250m 복원을 연구했습니다.

작동 방식. 공동 연구의 DCT 기반 RRDBNet ×8 복원은 저해상도 온도와 고해상도 참조의 공간 정보를 활용합니다. Bicubic·pyDMS와 비교하고 재학습 결과를 검토해, 단순 확대와 학습 기반 복원 사이의 차이를 평가했습니다.

03 · 선명함과 평균 오차만으로 정확도를 판단하는 문제 → 공간·현장 검증과 편차 분석

선택 이유. 선명한 경계가 정확한 온도를 보장하지 않으며, 전체 평균이 낮아도 특정 지역·월·시간대에서 오차가 클 수 있습니다. 평가 조건과 관측자료를 구분해 오차 구조를 살폈습니다.

작동 방식. Landsat으로 공간 복원 결과를 검증하고 ASOS로 현장 편차를 분석합니다. 이전·재학습 모델을 동일 조건에서 비교하는 결과와 별도 고정 테스트를 분리하고, 지역·월·시간대별 재학습·편차 보정 방향을 정리했습니다.

효과를 확인한 방법

동일 조건 비교에서 팀 재학습 모델의 RMSE는 2.359→1.382K로 약 41.4% 감소했습니다. 별도 고정 테스트 110패치의 RMSE 1.127K는 다른 평가 결과로 구분합니다. 이 전후 비교만으로 자료 정합·모델 구조 등 각 요소의 개별 인과 효과를 확정하지 않습니다.

본인 기여 · 기상청 과제 참여연구자
학습·검증 데이터 구성·정합, 자료 품질 점검, 복원 모델 비교와 오차 분석에 참여했습니다. 정량 성과는 공동 연구 보고서의 팀 결과입니다.

비교 근거 · 위성 연구의 전후 RMSE 비교와 평가 조건은 ‘성과’ 탭의 비교표·막대에서 확인할 수 있습니다. 해당 자료는 공동 연구 보고서에 기반해 정리한 값입니다.

같은 조건의 전후 비교와 별도 테스트를 구분

이전 checkpoint와 재학습 checkpoint의 동일 조건 비교로 개선 폭을 확인했습니다. 별도 고정 테스트는 train 881 / validation 110 / test 110 패치로 구성돼 있으며, best checkpoint의 결과를 따로 보고했습니다.

Landsat으로 공간 복원 오차를 살피고 ASOS로 도시·계절·시간대별 편차를 분석했습니다. 현장 오차는 지역과 시간대에 따라 달라, 하나의 평균값으로 모든 조건의 정확도를 일반화하지 않았습니다.
